### Perplexity AI Chat for JetBrains IDEs

A JetBrains IDE plugin that embeds Perplexity directly inside the IDE and lets you send selected code from the editor.

- [GitHub repository](https://github.com/Pralexio/PerplexityIntegration)
- [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/28929)
- Built with Kotlin and the IntelliJ Platform
